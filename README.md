# Gesture Lab

Сделал по приколу. Можно руками растягивать и крутить экран прямо в камере. Всё работает локально, видео никуда не отправляется.

## Как запустить

Нужны Git, камера и 64-битный [Python 3.12](https://www.python.org/downloads/). На Windows при установке Python отметь **Add Python to PATH**.

Склонируй репозиторий:

```sh
git clone https://github.com/plozzz126/hand.git gesture-lab
cd gesture-lab
```

**Windows:**

```powershell
.\start.bat
```

**Linux / macOS:**

```sh
bash start.sh
```

При первом запуске скрипт сам создаст `.venv` и поставит зависимости. При включении камеры скачается модель (~8 МБ), потом интернет не нужен. Повторный запуск — той же командой, на Windows можно просто открыть `start.bat` двойным кликом.

Нажми «Включить камеру». Соедини два указательных пальца и два больших, затем разведи руки. Повторное касание выключает фигуру. `F11` — полный экран.

Подготовлено для Windows / Linux x64 и macOS 14+ (Intel и Apple Silicon). На Intel Mac нужен именно Python 3.10–3.12. Фактически проверено на Linux.

Если камера не открывается — дай терминалу доступ к ней, закрой другие приложения с камерой или выбери другой источник в настройках. На Ubuntu / Debian для создания окружения может понадобиться `sudo apt install python3-venv libxcb-cursor0 libegl1 libgl1`.
